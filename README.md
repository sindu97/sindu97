## 🚀 Featured Projects

### 1. Offline Multilingual AI Tutor

An offline-first learning application designed to help students access
AI-assisted learning on low-cost laptops without an internet connection.

**Key engineering areas** - Full-stack application with a FastAPI
backend and React frontend. - Local LLM inference using Ollama and
Gemma. - RAG pipeline for textbook-grounded answers. - PDF/DOC ingestion
with OCR, table and equation extraction, and multilingual text
handling. - Voice interaction pipeline using IndicConformer
speech-to-text and Piper text-to-speech. - Performance optimization
through cached prompts, KV-cache prefill reuse, and model re-priming.

**Selected reported results** - Reduced first-token latency from
approximately **50 seconds to 2.4--4.3 seconds** in documented tests. -
Reduced false textbook citations from **4/10 to 0/10** in the reported
evaluation. - **154 passing tests** across the reported validation work.
